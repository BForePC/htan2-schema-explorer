HTAN files are organized by data level. Level 1 is raw instrument output (sequencing reads, raw images). Level 2 is aligned or compiled data (aligned reads, stitched images). Level 3 is derived data (variant calls, expression matrices, segmentation masks). Level 4 is summarized or integrated data (cell annotations, cell-by-feature tables). Clinical and biospecimen records describe participants and samples and have no level. The fileid-kit convention (BForePC) gives every file a consistent, traceable identifier across assays and processing stages. It is optional: centers can instead submit their existing de-identified filenames with a sample-to-biospecimen mapping. The identifier encodes participant, specimen index, assay, data type and file number.

The specimen index (0003) is a number within the filename, not the HTAN biospecimen ID; the manifest must link the two. For a file built from several specimens (ex. a jointly called VCF), record its inputs explicitly rather than relying on the filename.
